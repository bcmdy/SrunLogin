# SrunLogin .NET 项目整改记录

## 当前状态

主线项目已切换为 WPF：

- `SrunLogin.Core`：认证协议、加密、模型和工具类。
- `SrunLogin.Wpf`：当前桌面 GUI。
- `SrunLogin.Core.Tests`：协议迁移对照测试。
- `build.ps1`：发布 `SrunLogin.Wpf.exe`。

旧 WinForms GUI 和 Python 原版脚本已清理。图标已迁移到 `dotnet/SrunLogin.Wpf/Resources/icon.ico`。

## 已完成

1. 统一编码
   - 新增 `.editorconfig`，统一声明 UTF-8 和 CRLF。

2. 协议一致性
   - 登录 `info` JSON 使用紧凑序列化。
   - 查询字符串编码对齐 Python `urllib.parse.urlencode` 的空格 `+` 行为。
   - 补齐 `Accept-Language: zh-CN,zh;q=0.9`。
   - `SrunPortal` 实现 `IDisposable`。

3. WPF 重构
   - 新增 `SrunLogin.Wpf`。
   - 实现登录、查询、注销、帮助、配置保存、自动登录、托盘、单实例互斥体、循环检测和日志输出。
   - 配置文件 `config.json` 和日志文件 `app.log` 保持写入 exe 同级目录。

4. 稳定性与体验
   - 项目目标框架切换为 .NET 8 LTS。
   - 循环检测支持取消、防重入和失败退避。
   - `app.log` 超过 1MB 后滚动为 `app.1.log`。
   - 登录、查询、注销前统一校验 URL、账号、密码、IP、AC ID、循环参数和 Ping 主机。
   - 高级功能提供“允许自签名 HTTPS 证书”显式选项，默认关闭。
   - 日志框从左上角输出并自动滚动到底部。

5. 测试
   - 新增 `SrunLogin.Core.Tests`。
   - 覆盖 Base64、XXTEA、紧凑 JSON、HMAC-MD5、查询字符串、响应解析、HTML 提取和格式化输出。

## 验证命令

```powershell
dotnet run --project dotnet\SrunLogin.Core.Tests\SrunLogin.Core.Tests.csproj
dotnet build dotnet\SrunLogin.Wpf\SrunLogin.Wpf.csproj
.\dotnet\build.ps1
```
